# Archivo A.D.A. / PDFs públicos

Este directorio alojará únicamente PDFs aprobados para publicación pública.
Actualmente **no contiene documentos académicos publicados**.

Para publicar un documento:
1. Revisar versión, fecha, calidad académica y permiso para distribución.
2. Eliminar datos personales, credenciales, correos, enlaces privados y detalles sensibles.
3. Exportar un PDF accesible con nombre estable.
4. Copiarlo aquí y registrar una entrada en `src/docs/catalog.ts` con ruta `/docs/nombre.pdf`.
5. Comprobar visualización, descarga y despliegue.

Nunca registrar un documento que no exista físicamente en este directorio.
